HULIGANIGAMES ROGUELIKE — FINAL PROJECT CANDIDATE v49
Unity 6.6 (6000.6.5f1) · C# · uGUI · Legacy Input (KeyCode) · URP

СОСТАВ:
  Assets/            игровые сцены, скрипты, анимации, звуки и авторские PNG
  Packages/          зависимости URP и Unity
  ProjectSettings/   настройки Unity
  BUILD_WINDOWS_RU.md — пошаговая инструкция сборки Windows x64
  V49_FINAL_CHANGELOG_RU.md — список изменений

ИГРА:
  Обучение (уровень 0), две комнаты и Wraith King (уровень 1),
  две комнаты и Cyclops King (уровень 2), победа.
  Обычные враги: Skeleton, Cyclops; призываемые SkeletonMinion.
  Гоблины и их копья полностью исключены из финального проекта.
  Уровень 1: 3–4, 5–6 врагов; уровень 2: 7–8, 9–10.

УПРАВЛЕНИЕ ПО УМОЛЧАНИЮ:
  WASD — движение, мышь — прицеливание, ЛКМ — кинжалы,
  E — поднять предмет, Space — активный предмет,
  Q — переключение активного слота с рюкзаком,
  TAB — свойства/предметы, ESC — пауза.

ЗАПУСК В UNITY:
  1. Распакуй ZIP. В Unity Hub добавь папку с Assets/Packages/ProjectSettings.
  2. Открой под Unity 6000.6.5f1. Дождись установки URP и импорта.
  3. Загрузи Assets/Scenes/MainMenu.unity и нажми Play.
  4. Для Windows .exe: HuliganiGames → Build Final Windows x64.

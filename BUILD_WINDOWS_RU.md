# Сборка финальной версии для Windows

1. В Unity Hub откройте распакованную папку проекта под **Unity 6000.6.5f1**.
2. Дождитесь импорта пакета URP и всех ассетов, затем проверьте, что консоль без красных ошибок.
3. Перейдите в **File → Build Profiles** и убедитесь, что установлена поддержка **Windows Build Support (IL2CPP)** или Windows Standalone.
4. В верхнем меню редактора нажмите **HuliganiGames → Build Final Windows x64**.
5. После успешной сборки откройте папку **Builds/Windows-x64/**. Для публикации нужны **HuliganiGames.exe**, папка **HuliganiGames_Data** и остальные сгенерированные Unity-файлы.
6. Проверьте .exe на Windows (обе сцены, комнаты, музыку, боссов, награды, сохранение, поражение/победу).

В среде подготовки ZIP **Unity Editor недоступен**, поэтому .exe не собирался и игровое тестирование не проведено.
